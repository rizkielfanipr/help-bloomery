# Daily Briefing

| Fitur | Dokumen | Status tertulis | Indeks |
|---|---|---|---|
| Remediation | [PRD](remediation/prd.md) | Rancangan siap review; belum mengotorisasi implementasi, cleanup data, migration production, atau deployment | needs-review |
| Scoring & UI | [PRD](scoring-ui/prd.md) | Rancangan siap review; belum mengotorisasi implementasi, recompute production, migration production, atau deployment | needs-review |

Kedua PRD saling melengkapi: Scoring & UI mengatur metode nilai dan tampilannya, sedangkan partisipasi branch, role `STORE_STAFF`, assignment task, status `missing`, branch scope, scheduler, dan cleanup tetap mengikuti PRD Remediation (dinyatakan di Scoring & UI §1).

Path lama: `docs/daily-briefing-remediation-prd.md`, `docs/daily-briefing-scoring-ui-prd.md`.
